# Scene 03 — An old thought, found

Wen is drafting in an external document. After the sentence “A collection should help ideas grow, not just keep them.” appears, Wen deliberately opens the Grdn side panel and asks, “What did I keep about growing ideas?” The panel returns one illustrative saved reference, “Notes on digital gardens,” with provenance “From your Writing garden · kept in March.” Its original note excerpt is “Leave room for an idea to change.” Wen chooses that excerpt, brings it into the document as a block quote, and keeps the note visible in the sidebar. The document attributes the quote to the saved note.

This is an observational, static mock of an explicit Ask interaction with saved context. It does not imply the extension reads live document text or keystrokes automatically. The visitor cannot type into the mock document or panel.

The scene replaces the existing Type & letters garden with a 580px desktop / 400px narrow stage titled “An old thought, found” by Wen. Pointy joins Wen’s cursor at the shared companion offset, dwells through the initial writing, guides attention to the saved excerpt, and rejoins Wen before insertion. All transfers use shared handoffs. The scene uses one pausable clock for typing, panel, result, quote insertion, and actors; it starts above 60% visibility after navigation settles, pauses below 50%, and resumes at the frozen pose/content. The active border follows ownership. Reduced motion shows the completed document and saved note without animated cursor flights.

| Active clock | Beat |

| 0–1 s | Join Wen at the draft; observe the external document. |

After Lena completes, a quiet edge cue labelled “Find an old thought” points toward Wen’s scene and pans there only when clicked. The preceding cue is labelled “A better read next.” Both remain optional, track the wrapped target, and hide in view or after completion. No Pointy name appears in visitor-facing copy.

## Product evidence

The extension/sidebar direction is grounded in [Primer v2 issue #99](https://github.com/getcolex/primer-v2/issues/99). The local extension implementation sends the active tab URL/title and does not read live document keystrokes. This script deliberately uses an explicit Ask request instead of automatic live-text suggestions. The note and excerpt are illustrative original scene content, not quotations attributed to a real author.
